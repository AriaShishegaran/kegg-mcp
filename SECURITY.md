# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue.

Instead, open a private security advisory:

**[github.com/AriaShishegaran/kegg-mcp/security/advisories/new](https://github.com/AriaShishegaran/kegg-mcp/security/advisories/new)**

Include a description of the issue, its impact, steps to reproduce, and any suggested fix. Reports are acknowledged within 72 hours.

## Scope

Vulnerabilities in this server's code. Issues in the upstream [KEGG REST API](https://www.kegg.jp/kegg/rest/keggapi.html) itself are out of scope — report those to Kanehisa Laboratories.
